# Chrome Dino Runner 🦖

A simple endless runner game inspired by the Google Chrome Dinosaur game, built using Python and Pygame.

## 🎮 Features

- Dinosaur jumping mechanics
- Obstacles with randomly generated positions
- Collision detection
- Score tracking
- Increasing game speed over time
- Custom dinosaur and cactus sprites

## 🛠️ Technologies Used

- Python
- Pygame

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Haroon-Sheikh-3/chrome-dino-runner.git
```

### 2. Navigate to the project folder

```bash
cd chrome-dino-runner
```

### 3. Install Pygame

```bash
pip install pygame
```

### 4. Run the game

```bash
python main.py
```

## 🕹️ Controls

- **SPACE** — Jump
